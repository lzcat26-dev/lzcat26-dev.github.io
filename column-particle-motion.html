パーティクルの動かし方

パーティクル スクリプト

ビームのようにまっすぐ飛ばす、渦を巻かせる、といったパーティクルの動きの付け方です。Relic Clash のエクスカリバーのビームや魔法の渦を作ったときのやり方をまとめます。

結論

  • 向きと速さは、スクリプトから setSpeedAndDirection で渡す
  • 進む向きに長く伸ばしたいときは、facing_camera_mode: "lookat_direction" と custom_direction
  • 決まった形に動かしたいときは、particle_motion_parametric で位置を式で書く
  • 止めたいときがあるなら、くり返すエミッターは使わない

まっすぐ飛ばす

スクリプトから、向きと速さをまとめて渡します。

import { MolangVariableMap } from "@minecraft/server";

const vars = new MolangVariableMap();
vars.setSpeedAndDirection("variable.move", 100, player.getViewDirection());
player.dimension.spawnParticle("lzc:beam", pos, vars);

これで、パーティクルの側では variable.move.speed と variable.move.direction_x・_y・_z が使えます。

"minecraft:emitter_shape_point": {
  "direction": [ "variable.move.direction_x", "variable.move.direction_y", "variable.move.direction_z" ]
},
"minecraft:particle_initial_speed": "variable.move.speed",
"minecraft:particle_motion_dynamic": {
  "linear_acceleration": [ 0, 0, 0 ]
}

速さの単位は1秒あたりのブロック数です。100 なら1ティックに5ブロック進みます。エクスカリバーでは、ダメージの届く距離も1ティックに5ブロックずつ伸ばして、見た目とダメージをそろえています。

進む向きに伸ばす

ビームのすじのように、進む向きに長い形にしたいときは、板(ビルボード)を細長くして、向きを進む方向に合わせます。

"minecraft:particle_appearance_billboard": {
  "size": [ 12, 1.2 ],
  "facing_camera_mode": "lookat_direction",
  "direction": {
    "mode": "custom",
    "custom_direction": [ "variable.move.direction_x", "variable.move.direction_y", "variable.move.direction_z" ]
  }
}

lookat_direction は、指定した向きを軸にしたまま、できるだけカメラのほうを向いてくれます。横から見ても線が消えません。

決まった形に動かす(渦など)

particle_motion_parametric を使うと、出てからの時間で位置を式で決められます。下は、回りながら外へ広がって、少しずつ上がる渦の例です。

"minecraft:particle_motion_parametric": {
  "relative_position": [
    "math.cos(v.particle_random_1 * 360 + v.particle_age * 600) * (0.4 + 4.6 * math.sqrt(v.particle_age / v.particle_lifetime))",
    "(0.1 + v.particle_random_2 * 2.6) * (v.particle_age / v.particle_lifetime)",
    "math.sin(v.particle_random_1 * 360 + v.particle_age * 600) * (0.4 + 4.6 * math.sqrt(v.particle_age / v.particle_lifetime))"
  ]
}
  • v.particle_age * 600: 1秒に600度回る
  • v.particle_random_1 * 360: 粒ごとに回りはじめの角度をずらす
  • math.sqrt(v.particle_age / v.particle_lifetime): はじめは速く、だんだんゆっくり広がる

止めたいときがあるなら、くり返すエミッターは使わない

minecraft:emitter_lifetime_looping のエミッターは、ずっとくり返します。spawnParticle は出したあとに止める手段がないので、一度出すと消せません。

あとで止めたいものは、emitter_lifetime_once などの一回で終わるエミッターにして、スクリプトから0.1〜0.5秒ごとに出し直します。出し直しをやめれば、自然に消えます。

気をつけること

setFloat で渡した変数は、emitter_shape の中では使えませんでした。emitter_shape_point の direction などで使うと「unknown variable」のエラーになりました。色や大きさ(particle_appearance)と、particle_motion_parametric の式の中では使えます。

なので、長さや半径のような数字は setFloat で渡して particle_motion_parametric の側で使い、emitter_shape_point は {} のままにしておきます。向きのような3つ組の値は、setSpeedAndDirection を名前を変えて何回か呼べば、何本でも渡せます(variable.cu、variable.cv など)。

色は #AARRGGBB の順です。先頭の2けたが不透明度です。#RRGGBBAA のつもりで書くと、色がまったく変わります(私は水色のつもりが黄緑になりました)。

世界の外の高さに出すとエラーになります。計算で場所を決めていると、地面の下(Y -64 より下)などに出してしまうことがあります。system.runInterval の中でこれが起きると、毎回エラーが出続けるので、高さをしぼるか try で囲みます。

本人にだけ見せたいときは player.spawnParticle()。dimension.spawnParticle() は近くの全員に見えますが、player.spawnParticle() はその人にしか見えません。

パーティクルは自作のマテリアルを使えないので、壁越しに見せることはできません(壁を透けて見えるエンティティの作り方)。
