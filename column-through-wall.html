壁を透けて見えるエンティティの作り方

マテリアル エンティティ

壁の向こうにいるプレイヤーの輪郭を光らせて見せる、いわゆるウォールハックの見た目の作り方です。

LZ OUTLINE で使っているやり方で、元は Glowing Addon(kashiwa_mocchi さん)の仕組みです。

結論

  • 自作のマテリアルで depthFunc を Always にすると、壁があっても手前に描かれる
  • 体を少し大きくしたモデルをそのマテリアルで重ね、ステンシルで体の形の外側だけに描くと、輪郭になる
  • プロパティで出し入れする

1. マテリアルを作る

リソースパックの materials/entity.material に、2つのマテリアルを作ります。

{
  "materials": {
    "version": "1.0.0",
    "lzc_body:entity_alphatest": {
      "+states": [ "EnableStencilTest", "StencilWrite" ],
      "frontFace": { "stencilFunc": "Always", "stencilFailOp": "Replace", "stencilDepthFailOp": "Replace", "stencilPassOp": "Replace" },
      "backFace":  { "stencilFunc": "Always", "stencilFailOp": "Replace", "stencilDepthFailOp": "Replace", "stencilPassOp": "Replace" },
      "stencilRef": 2
    },
    "lzc_outline:entity_static": {
      "+states": [ "InvertCulling", "EnableStencilTest", "DisableDepthWrite", "Blending" ],
      "+defines": [ "USE_OVERLAY" ],
      "-defines": [ "FANCY" ],
      "depthFunc": "Always",
      "frontFace": { "stencilFunc": "NotEqual" },
      "backFace":  { "stencilFunc": "Equal" },
      "stencilRef": 2,
      "stencilReadMask": 2
    }
  }
}
  • lzc_body: ふつうの体に使う。描いたところに「ここは体」という印(ステンシルの 2)を残す
  • lzc_outline: 輪郭に使う。depthFunc: Always で壁を無視して描き、stencilFunc: NotEqual で体の印があるところには描かない

こうすると、大きくした体のうち、もとの体からはみ出たふちの部分だけが残って、輪郭になります。

2. 輪郭用のモデルを作る

プレイヤーと同じボーンのモデルを作り、キューブに inflate をつけて少しだけ大きくします。

{
  "name": "body",
  "parent": "waist",
  "pivot": [ 0, 24, 0 ],
  "cubes": [
    { "origin": [ -4, 12, -2 ], "size": [ 8, 12, 4 ], "inflate": 0.5, "uv": [ 0, 0 ] }
  ]
}

ボーンの名前と親子関係をプレイヤーと同じにしておけば、歩く・しゃがむなどのアニメがそのまま輪郭にもかかります。絵は、輪郭の色で塗った小さな画像で十分です。

3. プレイヤーにつなぐ

プレイヤーのクライアントエンティティで、体のマテリアルを lzc_body にし、輪郭のマテリアル・モデル・絵を足します。

"materials": {
  "default": "lzc_body",
  "cape": "lzc_body",
  "lzc_outline": "lzc_outline"
},
"geometry": {
  "lzc_outline": "geometry.lzc_outline"
}

輪郭のレンダーコントローラーは、光を受けないように ignore_lighting をつけます。

"controller.render.lzc_outline": {
  "geometry": "Geometry.lzc_outline",
  "textures": [ "Texture.lzc_outline" ],
  "ignore_lighting": true,
  "materials": [ { "*": "Material.lzc_outline" } ]
}

4. プロパティで出し入れする

ビヘイビアパックでプレイヤーに client_sync: true のプロパティを作り、それが 0 より大きいときだけ輪郭を描きます。

"render_controllers": [
  { "controller.render.lzc_outline": "!query.is_spectator && !variable.is_first_person && query.property('lzc:outline') > 0" }
]

一人称のときは自分の輪郭が画面をふさぐので、!variable.is_first_person で外しています。

LZ OUTLINE では、このプロパティを 1〜16 の数字にして、色の絵を16枚の配列から選んでいます。

特定の人にだけ輪郭を見せたいときは、特定の人にしか見えないエンティティの作り方 と同じく、setPropertyOverrideForEntity で見せたい人の側だけ値を変えます。

気をつけること

パーティクルではできません。パーティクルが使えるマテリアルは particles_add・particles_alpha・particles_blend の3つだけで、自作のマテリアルを指定できないためです。壁越しに見せたいものは、エンティティとして作ります。

プレイヤーの player.entity.json を上書きするので、同じようにプレイヤーを上書きしている別のパックとは、どちらか片方しか効きません。
