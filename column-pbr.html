PBR でブロックを光らせる・つやを出す

PBR リソースパック

バイブラントビジュアルズで、自作ブロックの一部だけを光らせたり、金属や床にちょっとしたつやを出したりするやり方です。

どれも、バイブラントビジュアルズ(またはレイトレーシング)のときだけ見た目が変わります。オフのときは、ふつうのブロックのままです。

結論

  • 色の絵と同じ場所に 〇〇.texture_set.json を置く
  • MER は R=金属っぽさ・G=光る強さ・B=ざらざら具合(4つ目の A は subsurface)
  • ブロック全体を同じにするなら数字3つ、一部だけ光らせるならMER の絵
  • MER の絵は透明度を全部 255 にして保存する

texture_set.json を置く

色の絵が textures/blocks/lzc_lamp.png なら、同じフォルダに lzc_lamp.texture_set.json を置きます。

{
  "format_version": "1.21.30",
  "minecraft:texture_set": {
    "color": "lzc_lamp",
    "metalness_emissive_roughness": "lzc_lamp_mer"
  }
}

4つ目の値(subsurface)も使うときは、キーを metalness_emissive_roughness_subsurface にして、4チャンネル(RGBA)の絵を指定します。名前の後ろの _subsurface まで書くのを忘れないようにします。

MER の3つの値

チャンネル意味0 のとき → 255 のとき
Rmetalness(金属っぽさ)金属でない → 金属
Gemissive(光る強さ)光らない → 強く光る
Broughness(ざらざら具合)つるつる → ざらざら

全体を同じにするなら、数字だけでいい

ブロック全体を同じ質感にしたいだけなら、絵を作らずに数字を書けます。

"metalness_emissive_roughness": [ 170, 0, 100 ]

これは、少し金属っぽく、光らず、ややつやがある、という設定です。私は金属の机をこのくらいにしています。床に「ほんの少しだけ」つやを出したいときは、[ 0, 0, 205 ] のように金属っぽさは0のまま、ざらざら具合を少しだけ下げています。

一部だけ光らせるなら、MER の絵を作る

ちょうちんの赤いところだけ、ランプのガラスだけ、のように一部だけ光らせたいときは、色の絵と同じ大きさの MER の絵を作って、光らせたいピクセルだけ G を上げます。

光らせたい部分がほかより色あざやかなら、「R・G・B のいちばん大きい値といちばん小さい値の差」が大きいピクセルを選ぶと、色に関係なくまとめて拾えます。私は差が 35 より大きいところを光らせました。こうすると、赤も青も1回で選べます。

G は 255 にしないほうがいいことが多いです。全部 255 だと光りすぎました。私の場合、赤は 80、青は 255 で落ち着きました。色によって、ちょうどいい強さはちがいます。

気をつけること: 透明度は全部 255 にする

ここがいちばんわかりにくいところでした。MER の絵を、透明度0のピクセルがある状態で PNG に保存したら、そのピクセルの R・G・B が全部0になっていました。透明なピクセルの色は捨ててしまう保存のしかたがあるためです。

MER の絵の4つ目のチャンネルは、本当の「透明」ではなく subsurface の値です。3チャンネルで使う場合も4チャンネルで使う場合も、透明度は全部 255 にして保存するのが安全です。

画像ソフトで作るときも、透明なピクセルの色を残す設定があれば、それをオンにしておきます(GIMP なら PNG を書き出すときの「透明ピクセルの色の値を保存」)。
