無敵時間を無視してダメージを与える方法

スクリプト ダメージ

ビームや炎のように、当たっている間ずっとダメージを入れる攻撃を作ると、ふつうのダメージでは無敵時間にはじかれて、思ったほど減らないことがあります。

Relic Clash では、エクスカリバーのビームや機銃掃射のように1ティックごとにダメージを入れる攻撃が多かったので、そのときのやり方をまとめておきます。

結論

  • applyDamage の cause を EntityDamageCause.override にする
  • ノックバックをおさえたいなら、すぐあとに強さ0のノックバックをかける

基本の形

import { EntityDamageCause } from "@minecraft/server";

target.applyDamage(6, { cause: EntityDamageCause.override, damagingEntity: player });

Relic Clash の機銃掃射は、1ティックごとに5ダメージをこれで入れています。

cause は文字ではなく本物の値を渡す

cause: "override" のように文字で書くと、読み込むときには何も言われず、ダメージを入れた瞬間に次のエラーが出ます。

TypeError: Native variant type conversion failed

@minecraft/server から EntityDamageCause を読み込んで、EntityDamageCause.override を渡します。

ノックバックをおさえる

damagingEntity に攻撃した人を入れると、ゲームのふつうのノックバックも一緒に入ります。1ティックごとにダメージを入れる攻撃だと、相手がずっと押し出されてしまいます。

いちばん簡単なのは、ダメージを入れたすぐあとに強さ0のノックバックをかけることです。これでノックバックはほぼ消えます。

target.applyDamage(amount, { cause: EntityDamageCause.override, damagingEntity: player });
target.applyKnockback({ x: 0, z: 0 }, 0);

damagingEntity をつけたままなので、倒したときに「誰が倒したか」もちゃんと残ります。

もうひとつのやり方: とどめのときだけ攻撃した人をつける

damagingEntity をつけなければ、ゲームのノックバックは入りません。ただ、まったくつけないと誰が倒したかが分からなくなるので、このダメージで倒れるときだけつけます。

import { EntityDamageCause } from "@minecraft/server";

export function hurtNoKnockback(target, amount, owner) {
  const hp = target.getComponent("minecraft:health")?.currentValue ?? 0;
  const lethal = hp > 0 && hp <= amount;
  const options = lethal && owner?.isValid
    ? { cause: EntityDamageCause.override, damagingEntity: owner }
    : { cause: EntityDamageCause.override };
  target.applyDamage(amount, options);
}

Relic Clash では、炎上・出血・毒などの持続ダメージと、エクスカリバーのビームをこの形にしています。

ただし、この形でもノックバックはほんの少しだけ入ります。押し出されることはなくなりますが、足が少し遅くなる程度の動きは残ります。

気をつけること

override は、リスポーン直後の無敵も無視して当たります。リスポーン地点の近くで攻撃が続くゲームでは、それも考えておく必要があります。

お試し用のアドオン

ここに出てきた3つのダメージの入れ方を、アイテムで比べられるアドオンです。見ているモブに、1ティックごとに1ダメージを15回入れて、実際に減った体力をチャットに出します。

  • 1. ふつうのダメージ: 無敵時間にはじかれて、ほとんど減らない
  • 2. override: 全部入るが、相手が押し出される
  • 3. override + ノックバック0: 全部入って、ノックバックもほぼない

アイテムはクリエイティブのインベントリの「装備」にあります。村人など、体力20のモブで試すと分かりやすいです。中のスクリプトは、このページのコードと同じ形です。
