サウンドの定義について

サウンド リソースパック

sound_definitions.json の書き方と、音を鳴らすときにつまずいたところのまとめです。「遠くで鳴らない」「全員に聞こえてしまう」「離れたほうが大きい」あたりは、だいたいここが原因でした。

結論

  • 聞こえる範囲を決めるのは、定義の volume ではなく、/playsound の volume と定義の max_distance
  • 自分にだけ鳴らすなら player.playSound()。/music は全員に聞こえる
  • 長い音には stream: true
  • 場所から鳴らす音はモノラル、耳もとで鳴る音や曲はステレオのまま

基本の形

{
  "format_version": "1.14.0",
  "sound_definitions": {
    "lzc.mortar.explode": {
      "category": "player",
      "max_distance": 96,
      "sounds": [
        { "name": "sounds/lzc/mortar_explode", "volume": 2 },
        { "name": "sounds/lzc/mortar_explode2", "volume": 2 }
      ]
    }
  }
}
  • sounds に何個か入れると、鳴らすたびにその中から1つ選ばれる
  • category で、設定のどの音量で大きさが変わるかが決まる(種類は次の節)
  • max_distance は、この距離まで聞こえる、という設定

category の種類

category は、設定のどの音量で大きさが変わるかを決めるものです。バニラの sound_definitions.json で使われているのは、次の10個です。

category効く音量の設定バニラでの使われ方
music音楽(/playsound で鳴らしたときは効かない)BGM(music.game など)
recordジュークボックス・音符ブロックレコード、ヤギの角笛
playerプレイヤープレイヤーの動き、効果がかかったときの音
blockブロックブロックを置く・こわす、ビーコンなど
neutral友好的なモブ動物や、敵でないモブ
hostile敵対的なモブゾンビ、ウィザースケルトン、ブリーズなど
ambient環境洞窟の音、バイオームの環境音
weather天気雨、雷
uiサウンドボタンのクリック、本のページをめくる音
bottle—ビンに水をくむ音など3つだけ

設定の名前は、だいたいの対応です。書かれていない・知らない名前の category は「サウンド」の音量で変わります。

music のいちばんの特ちょうは、左右の差がなくなることです。どこで鳴らしても、右から・左からという聞こえ方にならず、耳もとで流れているように聞こえます。曲や、画面全体の演出の音に向いています。逆に、場所から鳴っているように聞かせたい効果音を music にすると、どこで鳴っているのかわからなくなります。

気をつけたいのは、/playsound で鳴らすと music が効かないことです。category を music にしても、音楽の音量を0にしている人にも流れます。/playsound で鳴らした音は、music にしても効果音として扱われる、ということです。スクリプトの player.playSound() で鳴らしたときも同じです。

音楽の音量が効くのは、/music コマンドで流した音だけです。音楽の音量を0にしている人には、/music の音は聞こえません。

迷ったら、だれが出した音かで選ぶと自然です。プレイヤーの武器や技なら player、置いたブロックや仕掛けなら block、自作の敵なら hostile です。

参考: bedrock-samples(バニラの sounds/sound_definitions.json)、Bedrock Wiki「Sounds」

遠くで鳴らない: /playsound の volume

座標をつけた /playsound は、コマンドの volume で聞こえる範囲が決まります。volume を書かないと 1 で、だいたい16マスです。それより遠い人には鳴らず、コマンドは「成功0」になります。

playsound lzc.strafe.attack @a ~ ~ ~ 10

私は最初、定義の "volume" を大きくして範囲を広げようとしましたが、範囲は変わりませんでした。定義の volume は音の大きさだけで、聞こえる範囲とは別です。

離れたほうが大きい: max_distance のない音

バニラの random.explode を使ったら、ある程度離れたほうが音が大きく聞こえました。距離の設定がない古い音は、距離での小さくなり方がおかしくなることがあります。

なので、自分で max_distance をつけた定義を作り直して、そちらを鳴らしています。

全員に聞こえてしまう: /music と player.playSound

/music には、だれに聞かせるかを決める引数がありません。スクリプトから特定のプレイヤーで実行しても、全員に流れます。

1人にだけ鳴らしたいときは、スクリプトの player.playSound() を使います。

player.playSound("lzc.self.explode", { volume: 0.8, pitch: 1.2 });
player.playSound("lzc.bomb.throw", { location: here });

location をつけると、その場所から鳴っているように聞こえます。ほかの人にも聞かせたいときは、聞かせたい人それぞれに playSound を呼びます。投げた本人には耳もとの音、まわりの人には投げた場所からの音、のように分けることもできます。

私は、本人用とまわり用で定義を2つ作って鳴らし分けています。本人用は category を music にして、左右の差がない音を耳もとで鳴らします。まわり用は player にして、その場所から鳴らします。

shooter.playSound("lzc.self.fire");
for (const p of world.getPlayers()) {
  if (p.id !== shooter.id) p.playSound("lzc.fire", { location: shooter.location });
}

lzc.self.fire が music、lzc.fire が player の定義です。撃った本人は銃の音が頭の真ん中で鳴り、まわりの人には撃った方向から聞こえます。

止めるときは stopsound @s 音の名前 を、その人で実行します。ただし、/music で流した音は stopsound では止まりません。music stop を使います。

長い音には stream

"lzc.excalibur": {
  "category": "music",
  "sounds": [
    { "name": "sounds/lzc/excalibur", "stream": true, "volume": 0.3, "load_on_low_memory": true }
  ]
}

曲や、何十秒もある演出の音は stream: true にします。load_on_low_memory をつけておくと、メモリの少ない端末でも読み込まれます。

モノラルとステレオ

場所から鳴らす効果音は、モノラルにしています。曲や、本人の耳もとで鳴らす音はステレオのままです。わざわざモノラルに変える必要はありません。

おまけ: バニラの音を消す

同じ名前で、sounds を空にした定義を書くと、その音は鳴らなくなります。たとえば、剣を振ったときの空振りの音を消したいときはこうします。

"game.player.attack.nodamage": {
  "category": "player",
  "sounds": []
}

リソースパック全体に効くので、自分の武器だけでなく、すべての空振りの音が消えます。
