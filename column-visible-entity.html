特定の人にしか見えないエンティティの作り方

スクリプト エンティティ

使った本人にだけ見える目印や、仲間にだけ見えるマーカーを作りたいときのやり方です。

ふつうの setProperty だと全員の見た目が変わってしまいますが、プレイヤーごとにプロパティの値を上書きできる関数があるので、それを使います。

結論

  • エンティティに client_sync: true のプロパティを作る(最初は false)
  • リソースパックで、そのプロパティが true のときだけ描く
  • 見せたい人に player.setPropertyOverrideForEntity() で true を渡す。一度ではなく、くり返しかけ直す

1. ビヘイビアパック: プロパティを作る

"description": {
  "identifier": "lzc:marker",
  "is_spawnable": false,
  "is_summonable": true,
  "properties": {
    "lzc:visible": {
      "type": "bool",
      "default": false,
      "client_sync": true
    }
  }
}

client_sync: true がないと、リソースパックの側からこのプロパティが読めません。スクリプトで値を変えてもエラーは出ないので、気づきにくいところです。

2. リソースパック: true のときだけ描く

クライアントエンティティの render_controllers に、条件をつけます。

"render_controllers": [
  { "controller.render.lzc_marker": "query.property('lzc:visible')" }
]

最初の値は false なので、何もしなければ誰にも見えません。

3. スクリプト: 見せたい人だけ上書きする

player.setPropertyOverrideForEntity(entity, "lzc:visible", true);

これで、player から見たときだけ、このエンティティのプロパティが true になります。ほかの人から見ると false のままなので、見えません。

この関数は @minecraft/server の 1.19.0 で追加されました。manifest の版がそれより古いと、関数そのものがありません。

一度かけただけだと、すぐ消える

私がいちばんハマったところです。エンティティを出した直後に一度だけ上書きしたら、一瞬見えて、すぐに消えてしまいました。

見せている間は、くり返しかけ直す必要があります。0.5秒(10ティック)ごとで大丈夫でした。

import { system } from "@minecraft/server";

export function showOnlyTo(player, entity, ticks) {
  let elapsed = 0;
  const run = system.runInterval(() => {
    if (!player.isValid || !entity.isValid || elapsed >= ticks) {
      system.clearRun(run);
      try { player.removePropertyOverrideForEntity(entity, "lzc:visible"); } catch {}
      return;
    }
    player.setPropertyOverrideForEntity(entity, "lzc:visible", true);
    elapsed += 10;
  }, 10);
}

見せるのをやめるときは、かけ直しを止めて、removePropertyOverrideForEntity で上書きを消します。

ほかの使いどころ

自分で出したエンティティだけでなく、ほかのプレイヤーにも使えます。プレイヤーに光るプロパティを作っておけば、特定の人にだけ光って見せることもできます。

このやり方でプレイヤーに壁越しのアウトラインを付けるアドオンを、LZ OUTLINE として公開しています。
